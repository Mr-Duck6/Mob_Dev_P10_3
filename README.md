# Task Manager - Repository Pattern


## Опис проєкту

Task Manager - це застосунок, який дозволяє створювати та керувати списком завдань. Користувач може додавати нові завдання, позначати їх виконаними, видаляти та перемикатися між трьома способами збереження даних:

1. SQLite - реляційна база даних.
2. Hive - локальне NoSQL-сховище.
3. In-Memory - зберігання даних в оперативній пам'яті.


## Функціональні можливості

- Додавання нових завдань.
- Відображення списку завдань.
- Позначення завдань як виконаних.
- Зміна статусу виконання завдання.
- Видалення завдань.
- Перемикання між SQLite, Hive та In-Memory.
- Оновлення інтерфейсу після зміни даних.
- Автоматизовані тести репозиторіїв.

### Порівняння сховищ

| Сховище | Тип | Збереження після перезапуску |
|---|---|---|
| SQLite | Реляційна база даних | Так |
| Hive | NoSQL | Так |
| In-Memory | Оперативна пам'ять | Ні |

## Repository Pattern

У проєкті використано патерн Repository Pattern.

Його основна ідея - відокремити логіку роботи з даними від інтерфейсу користувача. Замість того щоб інтерфейс напряму працював із SQLite або Hive, він взаємодіє з репозиторієм через спільний інтерфейс.
